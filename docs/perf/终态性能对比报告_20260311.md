## 2. 压测口径

- 环境：`C:/anaconda3/envs/Gamma/python.exe`
- 工具：`tools/perf/bench_http.py`
- 指标：
  - CPU：服务进程 CPU 百分比（仅用于对比观察）

## 3. 变更清单（可回滚）

### 3.1 更新链路解耦（主页不再等待预处理/PKL）
- 后端更新状态仅覆盖 “抓取+快照”，预处理与 PKL 构建迁移到后台线程，并在 `/api/status` 暴露 `preprocess` 独立状态。
- 代码位置：[web_server.py](file:///d:/量化交易/中性1.8/apps/crypto_screener/app/web_server.py)

### 3.2 企业微信选币修复（MA/RSI 等条件补齐序列）
- `_config_needs_series` 增补 `condCloseMa/condMa/condRsi`，避免推送路径未附加 `series` 导致筛选全空。
- 代码位置：[web_server.py](file:///d:/量化交易/中性1.8/apps/crypto_screener/app/web_server.py)

### 3.3 预处理数据格式支持（Parquet）
- 预处理读取支持 `.parquet`，为后续“用预处理格式替代 CSV 文本解析”提供路径。
- 代码位置：[series_source.py](file:///d:/量化交易/中性1.8/apps/crypto_screener/app/series_source.py)

### 3.4 PKL 构建增量复用加速（内容不变跳过重算）
- 当源 CSV 仅 mtime 变化但最后时间戳未推进时，复用上次的 `series_*.pkl`/`factors_*.pkl` 条目，避免每小时无意义重算。
- 代码位置：[factor_cache_update.py](file:///d:/量化交易/中性1.8/数据获取/factor_cache_update.py)

### 3.5 前端交互顺滑（表格分片渲染）
- 主页表格渲染改为 `requestIdleCallback`/`setTimeout` 分片 append，降低主线程阻塞。
- 代码位置：[app.js](file:///d:/量化交易/中性1.8/apps/crypto_screener/web/app.js)
